# Moonshine

A backup of the Moonshine source files.

Credits to TurnFlashed, S4ys and Fito.

## How to use

- Clone this repository: https://github.com/sm64pc/sm64ex, branch `nightly`.
- Download the mod by cloning this repository or downloading the zip (`Code` -> `Download ZIP`).
- Copy all directories and paste them directly in the `sm64ex` directory. Answer yes when it asks for replacing existing files.
- You can now build the game.
