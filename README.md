# Render96 models

A backup of the Render96 models.

Credits to the [Render96](https://github.com/Render96/Render96ex) Team.

## How to use

Each ZIP file is a model pack.

To use a model pack:
- Download its ZIP.
- Put the ZIP inside the `res/packs` (`dynos/packs` also works) directory of the game.
- Launch the game, open the Options menu, go to `Model Packs` and enable the model packs you want.
