# OMM-HD texture pack

A texture pack for Odyssey Mario's Moveset.

This is not a full texture pack, it includes only elements added by OMM.<br>Use it with another texture pack like the Render96 HD one.

## How to use

To use this texture pack:
- Download the texture pack by clicking `Code` -> `Download ZIP`.
- Put the ZIP file inside the `res` directory of the game.
- Launch the game, the textures will load automatically.
