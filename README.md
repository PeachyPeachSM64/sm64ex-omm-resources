# Render96 levels

A backup of the Render96 remodeled levels.

Credits to the [Render96](https://github.com/Render96/Render96ex) Team.

## How to use

The Render96 levels only works with the following repositories:
- https://github.com/sm64pc/sm64ex, branch `nightly`
- https://github.com/Render96/Render96ex, branch `tester`

You need to compile the game manually to be able to use the Render96 levels:
- Clone one of the compatible repositories (see above).
- Download the levels by cloning this repository or downloading the zip (`Code` -> `Download ZIP`).
- For each of the `Render96_*` directory (each corresponding to a specific level), copy the `levels` and `actors` directories and paste them directly in the game repository. Answer yes when it asks for replacing existing files.
- You can now build the game.
